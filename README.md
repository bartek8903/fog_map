# Mario Fog Map 🎮

Prosta gra GPS w stylu Mario.

## Jak działa
- Włącza mapę OpenStreetMap
- Śledzi Twoją lokalizację GPS
- Odkrywa mapę jak “mgła wojny”
- Dodaje procent eksploracji
- Gra dźwięk i monety przy ruchu
- System achievementów

## Jak uruchomić
1. Otwórz stronę przez GitHub Pages
2. Kliknij “Dodaj do ekranu głównego” (na telefonie)
3. Włącz GPS

## Technologie
- HTML
- CSS
- JavaScript
- Leaflet.js

## Cel projektu
Zrobienie mini gry mobilnej z realnym ruchem w świecie
